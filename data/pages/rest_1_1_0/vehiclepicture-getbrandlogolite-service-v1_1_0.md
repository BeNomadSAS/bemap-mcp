# REST API, Service version 1.1.0



## Get all

Returns the logo picture of brand in picture file format.

HTTP method `GET`.
URI: `/bgis/service/vehicle/1.1/getbrandlogolite`

Sample : `/bgis/service/vehicle/1.1/getbrandlogolite?brandId=686f862d9992b5655f42c47a`

## Parameters

Mandatory parameters:
* `brandId`: Unique uuid of the brand.


## Response

The logo image of brand in picture file format.
