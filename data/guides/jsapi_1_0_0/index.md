# BeMap JS API v1

<p class="bemap-tagline">The original callback-style JavaScript API — map display, geocoding and routing. Kept for applications already built on it.</p>

<div class="bemap-callout">
<strong>Starting something new? Use v2.</strong> The current API is <a href="index.html#subpage-jsapi_2_0_0-index.md">BeMap JS API v2</a> — Promise-based, with typed requests, typed responses, typed errors and uniform cancellation, plus vector maps, 3D and the full electric-mobility range. v1 classes stay available throughout the 2.x line and are removed in 3.0. To move an existing application across, start with the <a href="index.html#subpage-jsapi_2_0_0-migration-from-v1.md">v1 &rarr; v2 cheat sheet</a>.
</div>
