# Electric Mobility - Vehicles



Access an extensive Electric Vehicles database, including images, WLTP information, battery capacity, charging speed.



## API references

** Vehicles data:**
- [Get brands](index.html#subpage-rest_1_1_0-vehicle-getbrands-service-v1_1_0.md): to get the list of vehicle brands.
- [Get motor types](index.html#subpage-rest_1_1_0-vehicle-getmotortypes-service-v1_1_0.md): to get the list of motor types.
- [Find vehicles](index.html#subpage-rest_1_1_0-vehicle-findvehicles-service-v1_1_0.md): to find a vehicle in the database.
- [Get vehicle info by level](index.html#subpage-rest_1_1_0-vehicle-getlevelvehicleinfo-service-v1_1_0.md): API helper to fill the drop-down list in application UI.

**Brand logo:**
- [Get brand logo](index.html#subpage-rest_1_1_0-vehiclepicture-getbrandlogolite-service-v1_1_0.md): to get the logo picture of brand in picture file format.
- [Get brand logo details](index.html#subpage-rest_1_1_0-vehiclepicture-getbrandlogo-service-v1_1_0.md): to get the logo picture of brand in JSON format.

**Vehicle pictures:**
- [Get views](index.html#subpage-rest_1_0_0-vehiclepicture-getviews-service-v1_0_0.md): to get a list of available views of a given vehicle.
- [Get all](index.html#subpage-rest_1_0_0-vehiclepicture-getall-service-v1_0_0.md): to get a list of available pictures of the vehicle.
- [Get one](index.html#subpage-rest_1_0_0-vehiclepicture-getone-service-v1_0_0.md): to get a picture of the vehicle.

## JS API v2

- [`bemap.EvVehicles`](index.html#subpage-jsapi_2_0_0-js-ev-vehicles.md): standalone JS wrapper around the vehicle catalogue. The same endpoints are also reachable via [`bemap.EvSmartRouting.getBrands()` / `getVehicles()`](index.html#subpage-jsapi_2_0_0-js-ev-smart-routing.md).
