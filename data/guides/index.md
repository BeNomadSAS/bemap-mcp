<div class="col-sm-5 index-group">
	<h4>Routing</h4>
	<div>
		<p>
			<span class="fas fa-lg fa-route index-icon float-right"></span>
			This documentation sets out the uses of BeNomad Routing services. It performs several computations based on the road network. With this service, you can perform:
			<ul>
				<li>Route calculation: Calculate optimal routes and ETAs for specific transportation modes (car, EV, bus, truck, taxi, pedestrian…) with different optimization criteria (tolls, highway, waypoints…).</li>
				<li>Isochrones: Show users how far they can go within a specified amount of time, distance, or energy.</li>
				<li>Origin destination matrix calculations: Calculate routes, distances, and ETAs between multiple origins and destinations in a simple and easy way.</li>
				<li>TraceRoute: Compute the most probable driving route from a GPS trace. Automatic correction of GPS measurements creates a clean route to be displayed on a map or used for other analysis.</li>
			</ul> 
		</p>
		<a href="index.html#page-index-routing.md">See more details</a><br/>
	</div>
</div>

<div class="col-sm-5 index-group">
	<h4>Electric Mobility</h4>
	<div>
		<p>
			<span class="fas fa-lg fa-charging-station index-icon float-right"></span>
			Improve EV driving experience with dedicated features like EV routing, charging station search, reachable areas, an EV database, and real-time car data.<br/>
			<ul> 
				<li>Assist users in locating charging stations, providing charging duration and cost information.</li>
				<li>Display the reachable area: Line connecting points representing the reachability without charging around a given start point.</li>
				<li>Find or display charging stations around an address, including real-time availability, pricing, or network information.</li> 
				<li>Estimate the charging duration using our precise charging curve algorithms.</li>
				<li>Provide an approximate cost based on the required charge and price list.</li>
				<li>Access an extensive Electric Vehicles database, including images, WLTP information, battery capacity, charging speed.</li>
			</ul> 
		</p>
		<a href="index.html#page-index-electric-mobility.md">See more details</a><br/>
	</div>

	<h4>Search</h4>
	<div>
		<p>
			<span class="fas fa-lg fa-map-marker-alt index-icon float-right"></span>
			Allow searching for information and data from the map: addresses, coordinates, POIs, map attributes, and geofences.
			<ul>
				<li>Convert a readable address into geographic coordinates. Could be used to display a location on a map. Available in Batch for large amounts of data.</li>
				<li>Convert geographic coordinates (latitude and longitude) into readable addresses. Available in Batch for a large amount of data.</li>
				<li>Provide the user with all the necessary information from the map. For example, it can be used to show traffic signs or road junctions in a geographical area.</li>
				<li>Set up a geographic polygon to track if an asset is within or outside the defined area.</li>
				<li>Find POIs (restaurants, hotels, etc.) around a location. Results can be limited by the walking/driving distance to reach the POI.</li>
			</ul>
		</p>
