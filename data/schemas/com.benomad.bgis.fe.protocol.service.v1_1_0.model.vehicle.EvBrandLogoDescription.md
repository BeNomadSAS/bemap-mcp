| Field  | Optional | Description |
|--------|----------|-------------|
| __brandId__ |             | Unique identifier of brand. Type: `String`. |
| __logo__ |             | Logo of the brand. Type: `list or array of byte`. |
| __pictureFileFormat__ |             | Image file format of the brand logo.<br/> Available values:<br/> - `GIF`: GIF format: Indexed color (8 bits per pixel).<br/> - `JPEG`: JPEG format: RGB (24 bits per pixel).<br/> - `NOT_SUPPORTED_VALUE`: Not supported value for this API version.<br/> - `PNG`: PNG 8 bit format: Indexed color (8 bits per pixel).<br/> - `PNG24`: PNG 24 bit format: RGB + alpha channel (32 bits per pixel).
