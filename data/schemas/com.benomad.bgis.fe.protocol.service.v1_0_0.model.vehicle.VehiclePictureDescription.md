| Field  | Optional | Description |
|--------|----------|-------------|
| __picture__ |             | Photo of the vehicle. Type: `list or array of byte`. |
| __pictureFileFormat__ |             | Image file format of the vehicle photo.<br/> Available values:<br/> - `GIF`: GIF format: Indexed color (8 bits per pixel).<br/> - `JPEG`: JPEG format: RGB (24 bits per pixel).<br/> - `NOT_SUPPORTED_VALUE`: Not supported value for this API version.<br/> - `PNG`: PNG 8 bit format: Indexed color (8 bits per pixel).<br/> - `PNG24`: PNG 24 bit format: RGB + alpha channel (32 bits per pixel).
| __vehicleUuidKey__ |             | Unique key identifier of vehicle. Type: `String`. |
| __view__ |             | View of the picture.<br/> Available values:<br/> - `FRONT`: Front View of the vehicle's picture.<br/> - `NOT_SUPPORTED_VALUE`: Not supported value for this API version.<br/> - `PERSPECTIVE`: Perspective View of the vehicle's picture.<br/> - `REAR`: Rear View of the vehicle's picture.<br/> - `SIDE`: Side View of the vehicle's picture.<br/> - `UP`: Up View of the vehicle's picture.
